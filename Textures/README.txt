CenterResources textures
========================
All files are 32-bit uncompressed .tga with an alpha channel, power-of-two sizes.
Replace a file with your own (same name, same size or any power-of-two size) and
RESTART the game client (a /reload is not enough for texture changes).

Mask.tga   128x128  White filled circle on transparent. Shapes the portrait and its dark backdrop.
Ring.tga   128x128  White ring (transparent centre). Drawn over the portrait edge; tinted by
                    class / reaction colour, so keep it white or grey.
Pip.tga     32x32   White filled dot used for the PvP flag; tinted by faction colour.
Bar.tga    256x16   Greyscale status bar fill. Tinted by health/power colour, so keep it white/grey.
                    Choose "Smooth (Bar.tga)" or "Flat" under Bar texture in the settings.

Tips: keep the Ring's outer edge touching the image border so it lines up with the Mask.
