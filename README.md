# CenterResources
WoW Forever AddOn To Center Player Frames

This is a nearly 100% AI Written addon.
It has custom Player, Pet, Target and Focus frames where the portrait is centered between the health and resource bars.

Version 2.5.2
- Player, Target, Pet and Focus frames exist and can be positioned.
- Portraits are clickable and default menus for frames display.
- WoW client Player, Target, Pet and Focus frames can be hidden.
- Custom frames are configurable through UI menu.
- Pet frame displays pet happiness.
- Native Forever client Aura manager displays auras in and out of combat as expected.
